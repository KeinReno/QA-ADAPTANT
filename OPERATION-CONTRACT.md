# Контракт операции

Машинная форма: OperationContract. Версия schemaVersion 0.1.0. Бизнес-эффекты — именованные required/conditional проверки flat field=equals с источником independent-read и deadline/interval. Обязательна хотя бы одна безусловная проверка. Предусловия и роли проверяются до dispatch. Значения effects утверждены вместе с operation hash, не вычисляются моделью во время прогона.

identityFields должны включать marker владения и все идентификаторы выбранных исходных сущностей. lookupBy=fixtureId — не достаточное доказательство: verifier сверяет единственность результата, marker, entity kind, response ID и все identityFields. Для ЦИЗ отсутствие безопасного fixture marker/однозначной корреляции блокирует адаптер, а не разрешает поиск «похожего» объекта. В 0.1 поддерживается плоский локальный ресурс; вложенные relations ЦИЗ требуют расширения адаптера.

conditional effect: appliesWhen оценивается на утверждённых inputs. Отсутствующее поле даёт UNKNOWN, не NOT_APPLICABLE. Асинхронный эффект считается VIOLATED только после исчерпания ограниченного ожидания при доступном авторитетном источнике; недоступность чтения = UNKNOWN. Никакой HTTP status сам по себе не закрывает effect.
