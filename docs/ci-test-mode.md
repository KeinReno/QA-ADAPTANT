# Режим прогона для локального ядра 0.1

Команда приёмки и CI:

```text
npm test
```

Она запускает `node --test --test-concurrency=1 --test-timeout=45000` по всем `tests/*.test.mjs`. Файлы не идут параллельно. Так снимается интермиттентный `INCONCLUSIVE` полного набора, который появлялся при одновременном запуске восьми файлов с Chromium.

`npm run test:parallel` оставлен как прежний параллельный запуск. Он не является режимом Stable и не заменяет `npm test`.

`npm run test:races` отдельно запускает три проверки, которые сами создают конкурентные процессы. Последовательный набор их не отменяет:

- второй START во время preflight;
- запись evidence при 1, 2 и 6 читателях файла;
- активный прогон при 1, 2 и 6 процессах OBSERVE.

Для следующих изменений обязательны обе команды: `npm test` и `npm run test:races`. Ожидание для `npm test`: 59 тестов, 0 падений, код выхода 0. `test:races` нужно продолжать смотреть: один fail-closed `INCONCLUSIVE` при шести наблюдателях не повторился в шести повторных запусках и десяти стрессах и не блокирует 0.1 Stable. `test:parallel` в критерий Stable не входит.
