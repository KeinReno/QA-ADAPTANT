## Что принято

Локальное изолированное ядро. Оно исполняет один утверждённый локальный сценарий на стенде `127.0.0.1`: Control, Browser, Verification, одна бизнес-мутация, проверка эффектов, журнал evidence с отдельными коммитами и восстановление после большинства аварий.

Обязательные проверки следующих изменений:

```text
npm test
npm run test:races
```

`npm test` — 59 тестов, `--test-concurrency=1`. `npm run test:races` — второй START во время preflight, запись evidence при 1, 2 и 6 читателях, активный прогон при 1, 2 и 6 процессах OBSERVE. `npm run test:parallel` в критерий Stable не входит.

Независимый прогон: 5×59/59, код выхода 0. Повторные race-прогоны 6/6. Стресс 6 процессов OBSERVE: 10/10, одна мутация. Схемы 0.1.0 без изменений.

## Ограничения

Stable не разрешает мутации Dev и не подключает ЦИЗ.

До следующего этапа остаются: доверенная аутентификация и авторизация владельца, авторизация входных значений, внешний анкер evidence, серверная семантика создания объекта. Локальный реестр не заменяет эти проверки. Ответ HTTP 201 сам по себе не доказывает, что объект был новым.

Остаточный риск P3: первый запуск `npm run test:races` один раз дал fail-closed `INCONCLUSIVE` вместо PASS при шести наблюдателях. Шесть повторных запусков и десять целевых стрессов прошли. Ложного PASS, повторной мутации и потери подтверждённого журнала не было. Этот тест нужно продолжать смотреть в CI.

Ядро не выполняет произвольное человеческое поручение. Построение сценария и работа с ЦИЗ — отдельный этап 0.2: доверенное утверждение, подлинность окружения, внешний анкер, адаптер ЦИЗ и исследование интерфейса. Доверенный контур должен быть готов раньше любых мутаций на Dev.
