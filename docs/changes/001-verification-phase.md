# CR-001 — единственный писатель на фазу верификации

Схемы 0.1.0 и hashes замороженного слоя не меняются. Уточнение реализации: Control владеет жизненным циклом журнала, но делегирует запись independent-read envelopes отдельному Verification Worker на исключительную фазу VERIFYING. В этой фазе Control не дописывает evidence/events одновременно с verifier, Browser завершён. Verifier использует общий RunStore, самостоятельно перечитывает исходные артефакты и выполняет GET. Затем RESULT {verdict, reads} возвращается родителю, родитель перечитывает persisted store и повторяет coverage перед публикацией результата.

Причина: сохранить отдельный процесс и независимое чтение без дополнительного IPC ACK на каждый polling observation. Запись producer=verification допустима только в назначенном процессе; ни Browser, ни пользовательский payload не выбирает producer.

Критерий: отсутствие одновременных писателей, непрерывная цепочка, kill verifier не даёт PASS, RESULT соответствует тому, что лежит на диске. Ошибка записи/неполный tail → INCONCLUSIVE. Если Control продолжает писать при активном verifier, изменение отклоняется; вернуть sole Control writer с ACK.

Статус: согласовано основным агентом как минимальное уточнение для реализации, ожидает независимого code review Luna. Это не ослабляет проверку происхождения/полноту evidence и не принимается по документу без проверки кода.
