# Зависимости и решения переиспользования

Новая установка независима от node_modules архивов. package-lock.json фиксирует фактически установленные версии. zod 4.6.7 — MIT (node_modules/zod/LICENSE), playwright/playwright-core 1.63.0 — Apache-2.0 (соответствующий LICENSE); браузерные бинарники распространяются отдельно с upstream notices. Перед распространением продукта сохранить лицензии и third-party notices браузера. Node builtins — без дополнительных библиотек.

Старый код не копировался. Лицензия собственных архивных репозиториев не установлена как разрешение на публичную публикацию; текущее решение REWRITE без переноса файлов. React Flow/Dockview не установлены в ядро: их лицензии и точные версии проверяет WP-05 при внедрении. Нет скрытого bridge к QA-v2.

AF_v4/qa — документационный источник: README различает Honest Gate и probe/watch, schemas содержит scenario/test-run/known-quirk, scripts и e2e присутствуют. Его историческая работоспособность и причины неудачи не проверены в этой итерации; REJECT runtime reuse, EXTRACT только проверенные сценарные знания после source/runtime сверки. Его tests не запускались. Не утверждать, что красивый watch равен бизнес-проверке.
